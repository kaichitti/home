AviUtl ExEdit2 / AviUtl 1.10 向け　自動編集ツール

無音を切る。
毎回、同じように。

DetCut は動画の音声を解析して、無音カット・テロップ・SE・BGM を配置した AviUtl のプロジェクト（.aup2 / .exo）を書き出すツールです。判定はすべて決まったルールで行うので、同じ素材と設定なら出力はバイト単位で一致します。

GitHub でソースを見る 動作環境を確認する

Deterministic

同じ入力なら、
同じ出力。

自動編集の結果が実行のたびに少しずつ変わると、どこを直したのか分からなくなります。DetCut は乱数もネットワークも使わず、しきい値と区間の計算だけで判定します。2回実行して出力を比べるコマンドも付いています。

$ detcut verify sample_talk.mp4 -p presets/gadget_review.yaml
  一致  sample_talk.aup2         ee3633535fbd76ed…c1c5
  一致  sample_talk.exo          d7575d945e138e7f…ce44
  一致  sample_talk.report.csv   5364524738827282…07ab1
  一致  sample_talk.timeline.json 8d79fc8698f60921…eb22
決定論性チェック: OK（2回の出力がバイト単位で一致）

  • 音量は整数で計算

    10ミリ秒ごとの音の大きさを整数の二乗和で求め、しきい値と比べるだけ。CPUやライブラリの違いで判定が揺れません。

  • フレームは分数で

    29.97fps は 30000/1001 のまま扱い、切り捨て・切り上げを整数で計算します。小数の丸めで1フレームずれることがありません。

  • AIは文字起こしだけ

    テロップ用の文字起こし（faster-whisper）だけが任意のAI段です。結果はファイルに保存し、直した字幕を使えば以降はAIなしで毎回同じテロップになります。

Features

カットから
テロップ・SE・BGMまで

色は、それぞれの機能が AviUtl のタイムラインに置くオブジェクトの種類です。利用時間や回数の上限はなく、処理はすべて手元のPCで行います。

カット

  • 無音カット（前後の余白つき）
  • 咳・クリックなど短い音の除去と、近い区間の結合
  • 完全には切らずに間を詰める圧縮モード
  • 手動で「残す区間」「切る区間」を指定

テロップ

  • 文字起こしからテロップを自動配置任意のAI
  • 表記ゆれの辞書置換（アイフォン → iPhone）
  • 句読点・助詞で改行、行頭禁則とぶら下げ
  • 端をカット位置に吸着（編集点吸着）

SE・BGM

  • キーワード・長いカットの直後・章の頭に SE
  • BGM をループ配置し、話している間は音量を下げる
  • 候補が重なったら優先度で決定（乱択なし）

演出と操作

  • 同じ画が続いたら拡大率を 100% / 110% で切り替え
  • 波形とカット位置を見ながら調整できる GUI
  • テロップ＋SE の定番の組み合わせを1クリックで作るボタン
  • まとめて処理できるコマンド（CLI）

Getting started

使い方

  1. 準備する

    Python 3.11 以上と FFmpeg を入れて、setup_windows.bat をダブルクリック。必要なライブラリとサンプルの SE・BGM が用意されます。

  2. 動画をドロップして確認する

    run_gui.bat に動画をドロップ。波形の上で残す区間を確認し、しきい値を調整します。音量分布から決めた提案値も表示されます。

  3. 書き出して AviUtl で開く

    「書き出し」で .aup2 と報告書を作成。AviUtl2 で開いて仕上げます。従来版 AviUtl では .exo を読み込みます。

$ detcut run 動画.mp4 -p presets/gadget_review.yaml -t both
$ detcut analyze 動画.mp4      # 音量分布としきい値の提案
$ detcut transcribe 動画.mp4   # 文字起こしだけ（直してから使う）

FAQ

よくある質問

最新の AviUtl2 で開けますか？

.aup2 には公式の仕様書がないため、公開されている実機の保存ファイル（AviUtl2 2.00 beta53a 前後）を元に書き出しています。お使いの AviUtl2 で動画・音声・テキストを置いて保存したファイルを detcut harvest で読み込ませると、そのキー構成で書き出すようになります。

AIは使いますか？

使うのはテロップ用の文字起こし（faster-whisper）だけで、使わなくても無音カットや SE・BGM は動きます。文字起こしの結果は JSON と SRT で保存されるので、誤字を直してから使えます。

料金はかかりますか？

かかりません。処理はすべて手元のPCで行い、利用時間や回数の上限もありません。ソースコードは GPL-3.0 で公開しています。

Mac や Linux でも使えますか？

DetCut 自体は Python なので動きますが、書き出したファイルを開く AviUtl が Windows 専用です。WSL などで作る場合は、パスを C:\ 形式に置き換える設定（output.path_map）があります。

どんな動画に向いていますか？

1人で話す動画（ガジェットレビュー、解説、トーク）の粗編集に向いています。BGM が大きく入った素材は無音の判定が難しいので、detcut analyze で音量分布を見てしきい値を決めてください。
