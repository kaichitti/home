# fellow

レビュー/ブログ向けの軽量WordPressテーマ。

リスト型の記事一覧、レビュースコアダイヤル、プラグイン非依存のパンくずと目次を備えています。
共用サーバー(XREA等)でも軽快に動くよう、CSS/JSは各1ファイル、ビルドツール依存はゼロです。

- 必要環境: WordPress 6.3 以上 / PHP 8.0 以上
- ライセンス: GPL v2 or later

---

## 導入手順

1. 管理画面の **外観 > テーマ > 新規追加 > テーマのアップロード** から `fellow.zip` をアップロード
2. 「有効化」をクリック

この2ステップで表示できる状態になります。以下は好みに応じて設定してください。

### メニューの割り当て

**外観 > メニュー** で、作成したメニューを以下の位置に割り当てます。

| 位置 | 表示場所 |
|---|---|
| ヘッダーメニュー | ヘッダー右側。スマホではハンバーガー内 |
| フッター「サイト」メニュー | フッター左端の「サイト」列 |

どちらも未割り当てなら、その部分は表示されません。

### 初期設定の状況を確認する

**外観 > fellow 設定** の先頭に「初期設定の状況」があります。
テーマ選択画面に出る見本は各所を設定し終えた状態なので、未設定のままだと見本とかなり違って見えます。
何が残っているかはここで確認できます。

特に注意が必要なのが **設定 > 表示設定** の「ホームページの表示」です。
ここが「固定ページ」だとトップは固定ページの中身がそのまま出るため、
**紹介の帯・カテゴリー導線・ピックアップ・リスト型一覧はまとめて使われません**。
見本と同じ構成にしたい場合は「最新の投稿」を選んでください。

### ウィジェット

**外観 > ウィジェット** に3つのエリアがあります。
有効化した時点でサイドバーが空だった場合は、サイト内検索・カテゴリー・アーカイブ・最近の記事を自動で配置します
(すでに何か置かれている場合は触りません)。不要なら削除して構いません。

| エリア | 表示場所 |
|---|---|
| サイドバー | 本文の横。記事詳細・記事一覧・アーカイブ・検索結果・固定ページ |
| サイドバー(スクロール追従) | サイドバー下部。スクロールしても画面内に残ります |
| フッターウィジェットエリア | フッターの列 |

- サイドバーの2エリアが**両方とも空のときは、サイドバー自体が表示されず本文が全幅**になります
- 「サイドバー(スクロール追従)」に **fellow 目次** ウィジェットを置くと、読みながら参照できる目次になります

## カスタマイザーの設定項目

**外観 > カスタマイズ** から設定します。テーマファイルを直接編集する必要はありません。

| セクション | 項目 | 説明 |
|---|---|---|
| 色 | アクセントカラー | 見出しの飾り線、タグ、ボタン等に使われます。初期値 `#C2EEF2` |
| サイト基本情報 | ロゴ | 未設定ならサイト名がテキストで表示されます |
| SNSリンク | X / RSS / Feedly | 入力したものだけフッターに表示されます。空欄なら非表示 |
| トップページ | 紹介の帯 | ヘッダー下の帯の表示/非表示 |
| トップページ | カテゴリー導線 | 記事の多いカテゴリーを最大8件、上部に並べます |
| トップページ | 帯の見出し / リード文 | 空欄ならサイト名とキャッチフレーズが入ります |
| トップページ | ピックアップ記事 | 「先頭に固定」した記事 / 最新の記事 / 表示しない |
| トップページ | ピックアップの件数 | 2〜5件 |
| レイアウト | サイドバーの位置 | 右 / 左 / サイドバーなし(1カラム) |
| レイアウト | 本文の1行あたり文字数 | 65 / 70 / 75文字。読みやすさの調整用 |
| SEO | メタタグの出力 | description / OGP / Twitter Card。SEOプラグイン検出時は自動停止 |
| SEO | 構造化データの出力 | BlogPosting / WebSite |
| SEO | SNSシェア用の既定画像 | アイキャッチが無い記事で使われます(1200x630px 推奨) |
| SEO | X のユーザー名 | シェア時のカードに表示されます |
| SEO | noindex設定 | タグ / 日付・著者アーカイブ |
| fellow 機能設定 | ヘッダーの検索ボックス | 表示 / 非表示 |
| fellow 機能設定 | ヘッダー固定 | スクロール時にヘッダーを上部に固定するか |

404ページだけは、設定にかかわらず常に1カラムです。

## レビュースコア(スコアダイヤル)

レビュー記事に0.0〜10.0のスコアを表示できます。プラグインは不要です。

1. 投稿の編集画面を開く
2. サイドバーの **レビュースコア** に数値を入力(例: `8.4`)
3. 公開すると、本文下にスコアダイヤルが、記事一覧のカードにはスコアのバッジが表示されます

**スコアを入力しなければ、その記事にはダイヤルもバッジも表示されません。**
レビュー記事とそれ以外を同じブログで混在させても自然に成立します。

レビュー機能自体を使わない場合は、**外観 > fellow 設定** からオフにできます
(入力済みのスコアは削除されません)。

## 記事内パーツ

ブロック挿入画面(左上の + ボタン)の **パターン > fellow の記事パーツ** から挿入できます。

| パーツ | 用途 |
|---|---|
| ふきだし(左/右) | 会話形式の補足。アイコン画像は差し替えてください |
| ステップ(手順) | 番号付きの手順説明 |
| FAQ | 質問と回答の並び |
| キャプションボックス | ラベル付きの囲み。「注意」版もあります |
| ボックスメニュー | 関連ページへのリンクを並べる |
| バナーリンク | 「あわせて読みたい」等の1本のリンク |
| タブ切り替え | 見出しがタブ名になります |
| アコーディオン | クリックで開閉する折りたたみ |

挿入後はすべて通常のブロックなので、文字も色も自由に編集できます。

- **タブ**はJavaScriptが無効な環境では、見出し付きの段落として順に並びます。内容は全部読めます
- **アコーディオン**はHTMLの `details` 要素なので、JavaScriptなしで開閉します
- タブやステップの見出しは、記事の目次には入りません

### ブロックスタイル

リストや引用などを選択すると、右のサイドバーに fellow 用のスタイルが出ます。

| ブロック | スタイル |
|---|---|
| リスト | チェック / 注意 |
| 引用 | 線だけ |
| 画像 | 枠線つき |
| テーブル | コンパクト |
| 区切り | ドット |

## 目次

本文中の見出し(h2 / h3)から自動生成されます。設定は不要です。

- **本文内**: 最初の見出しの直前に挿入されます。スマホでは折りたたみ表示
- **サイドバー**: 「fellow 目次」ウィジェットを置いた場合のみ

見出しが2つ未満の記事では表示されません。
サーバー側で生成しているため、JavaScriptが無効な環境でも目次は機能します。

## よくある質問

**Q. サイドバーが表示されません**
サイドバーのウィジェットが空になっています。**外観 > ウィジェット** から何か配置してください。
または、カスタマイザーで「サイドバーなし(1カラム)」が選ばれていないか確認してください。

**Q. フッターのクレジット表記を消したい**
**外観 > fellow 設定** から非表示にできます。GPLライセンスのため表記の義務はありません。

**Q. 抜粋(記事の要約)を自分で書きたい**
投稿編集画面の「抜粋」欄に入力すると、そちらが優先されます。
未入力の場合は本文の最初の段落が自動で使われます。

**Q. ピックアップ記事に出したい記事を選びたい**
投稿一覧で記事を「先頭に固定」してください(投稿編集画面の「公開」>「表示状態」から設定できます)。
カスタマイザーで「最新の記事」を選べば、固定しなくても新しい順に自動で並びます。

**Q. ピックアップした記事が下の一覧に出てきません**
重複を避けるため、意図的に除いています。カテゴリーやアーカイブからは通常どおりたどれます。

**Q. SEOプラグインを使っています。設定は必要ですか**
不要です。Yoast SEO / Rank Math / All in One SEO / SEO SIMPLE PACK などを検出すると、
テーマ側のメタタグ出力は自動的に止まります(二重に出るのを避けるため)。
レビュースコアの構造化データ(Review)だけは、テーマ固有のデータなので出力を続けます。

**Q. レビューの★を検索結果に出したい**
投稿編集画面の「レビュー対象の名前」に商品名を入れてください(空欄なら記事タイトルが使われます)。
スコアと合わせて Review の構造化データとして出力されます。
実際にリッチリザルトが表示されるかは Google の判断になるため、
公開前に[リッチリザルトテスト](https://search.google.com/test/rich-results)での確認をおすすめします。

**Q. アイキャッチ画像を設定していないとどうなりますか**
一覧では画像枠そのものが表示されず、タイトルと抜粋だけのすっきりした行になります。
画像を設定した記事だけ、行の右側に小さなサムネイルが出ます。
